# Task 14 실제 생성 및 검색 평가

2026-10-14 기준, 실제 생성 출력으로 고정 질문 100개를 네 조건에서 검색했다. 재작성 B는 전체·출처별 Hit@5와 MRR@5 비저하 기준을 통과했다. HyDE 단독 C는 GitHub Hit@5 저하로 기준에 실패했다. 결합 D는 검색 지표를 통과했지만 대표 질문의 가상 문서에서 사실과 다른 서술이 확인되어 채택을 보류한다. T13-2 연결 시 인계할 기본 설정은 `rewrite_enabled=True`, `hyde_enabled=False`다.

- B−A: 전체·출처별 두 지표 모두 비저하. 전체 정답 문서 적중은 84/95에서 91/95로 증가했다.

대표 양성 14개에서 A/B/C/D의 Hit@5는 각각 0.928571/1.000000/1.000000/1.000000, MRR@5는 0.892857/0.928571/1.000000/0.964286이다. 대표 결과만으로 전체·출처별 판정을 대체하지 않았다.

부정 5개는 Hit·MRR 분모에서 제외하고 N/A로 유지했다. 반증 문서 검색은 A/B/C에서 각각 5/5, D에서 4/5다. 반증 검색은 답변의 적절성이나 가상 문서의 사실 정확성을 보증하지 않는다.

## 3. 실패와 회귀를 포함한 기록

400행 모두 보존했다. 정상 변환에 대한 실제 검색은 389회이며, 변환 실패 11행은 검색 없이 기록했다. 양성 실패는 Hit=0·RR=0으로 집계하고 부정 실패는 N/A와 별도 진단으로 유지했다. 실패 문항을 평가에서 빼거나 원질문으로 대체하지 않았다.

| 생성 단계 | 실제 호출 | 성공 | 실패 또는 생략 |
|---|---:|---:|---|
| 재작성 | 100 | 97 | Q060, Q070, Q094: 필수 식별값 손실 |
| 원질문 HyDE | 100 | 96 | Q060, Q081, Q082, Q094: 필수 식별값 손실 |
| 재작성 질문 HyDE | 97 | 96 | Q100: 필수 식별값 손실; Q060, Q070, Q094: 선행 실패로 생성 생략 |

B의 순위 회귀는 Q016, Q017, Q025, Q026, Q030, Q033, Q041, Q053, Q055, Q057, Q060, Q072, Q094의 13개다. 전체 평균 개선이 개별 문항의 비저하를 뜻하지 않는다. 문항별 순위 변화는 [검색 보고서](../data/eval/t14-live-20261014-final/report.md)에 기록했다.

대표 15개 원질문·재작성·C/D 가상 문서와 허용 원문을 대조했다. 재작성은 주요 질문 대상을 유지했지만 Q010·Q077에서 ART 명칭을 추가했으므로 RawTherapee 참고 원문과 ART의 지원 범위를 구분해야 한다. 연결 시 제품 범위를 제약으로 전달하고 최종 답변은 원질문과 실제 근거를 기준으로 작성한다. HyDE에는 다음의 의미 위험이 남았다.

| 문항 | 확인된 가상 문서 문제 | 허용 원문 기준 |
|---|---|---|
| Q008 | C는 Edge stopping 증가를 제시하고, D는 정확한 옵션 이름 없이 Iterations를 제시 | `rawpedia:Tone_Mapping`의 `Reweighting Iterates` 증가 설명 |
| Q092 | C/D가 재빌드의 효과를 확인된 조치처럼 서술 | `issue-comment:5103254495`는 AppImage 사용과 캐시 삭제 효과를 확인 |
| Q096 | D가 JXL 품질 슬라이더 활성화와 값 50 설정 절차를 제시 | `issue-comment:4711197631`은 옵션 부재와 고정 품질을 명시 |

따라서 C는 지표 실패로, D는 의미 위험으로 기본 채택에서 제외한다. 가상 문서는 검색 입력에만 사용하며 실제 답변 근거로 전달하지 않는다. 후속 HyDE 변경은 새로운 프롬프트 버전과 실제 생성 기록으로 다시 평가해야 한다.

## 4. 실제 생성 부담과 실패한 선행 실행

최종 실험은 실제 생성 297회를 수행했다. 각 호출의 측정 시간을 합산하면 1,732,661.58ms이며 호출당 평균은 5,833.88ms다. 단계별 평균은 재작성 4,423.51ms, 원질문 HyDE 6,728.54ms, 재작성 질문 HyDE 6,365.54ms다. 병렬 호출을 합산한 값이므로 전체 경과 시간과 같지 않다. B와 D가 공유한 재작성 호출은 한 번만 셌다.

최종 검색은 생성 캐시를 재생하므로 그 단계의 신규 생성 호출은 0회다. 이를 실제 최초 생성 시간 0ms로 해석하지 않는다. 호출별 시간과 원출력은 캐시에, 재생 중 검색 시간은 JSONL에 남겼다.

앞선 `hyde_v2` 실제 생성은 298회를 수행했으나 가상 문서 검색 입력이 554토큰으로 T9의 256토큰 한도를 초과하여 검색 실행을 중단했다. 이 실행은 유효한 A/B 결과로 사용하지 않는다. [선행 생성 기록](../data/eval/t14-generation-live-20261013.json)을 보존했다. 이후 한국어 조사·소수 식별값 판정 문제를 보완하고 HyDE를 영어 50~100단어로 명시한 `hyde_v3`로 100개 전체를 새로 생성했다. 임베딩 모델이나 토큰 한도를 바꾸거나 초과 입력을 잘라내지 않았다.

## 6. 연결 인계와 제한

T14 단독 구현과 실제 평가 기록을 확보했다. T13-2 그래프 연결과 연결 후 경로 회귀는 아직 수행하지 않았으며 [실행 플랜 §8](T14_execution_plan.md#8-t13-2-완성-후-그래프-연결-계획)의 별도 후속 단계다. 재작성 실패 전파, 원질문 유지, 출처 필터 보존, 가상 문서의 근거 유입 방지를 연결 시 검증한다.

이번 결과는 고정 질문셋과 한 번의 최종 생성 캐시에 대한 결과다. 프롬프트를 같은 질문셋에서 보완했으므로 별도 검증셋의 일반화 성능을 주장하지 않는다. 기존 출처 미검증 자료는 그대로 보류 상태로 보존한다.
